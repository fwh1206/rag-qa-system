# RAG 智能问答系统部署指南

## 1. 环境要求

| 依赖 | 版本建议 | 说明 |
| --- | --- | --- |
| Python | 3.12 | 项目在 Python 3.12 下开发与测试 |
| MySQL | 8.0 | 保存用户、会话、历史与登录 token |
| 大模型 API | DeepSeek 或任意 OpenAI 兼容接口 | 必须提供 API Key |
| Windows（可选） | Word 或 WPS | 仅解析旧版 `.doc` 时需要，Linux 建议先转 `.docx` |

## 2. 本地开发启动

首次部署：

```powershell
cd C:\Users\wang0\Documents\rag问答系统
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

编辑 `.env`，至少填写：

```dotenv
DEEPSEEK_API_KEY=你的密钥
RAG_DB_HOST=127.0.0.1
RAG_DB_PORT=3306
RAG_DB_USER=root
RAG_DB_PASSWORD=你的MySQL密码
RAG_DB_NAME=rag_qa_db
```

启动：

```powershell
.\venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

访问 <http://127.0.0.1:8000>。

### 使用项目自带脚本后台启动

```powershell
.\_start.ps1
```

日志写入 `logs/server-8000.out.log` 与 `logs/server-8000.err.log`。端口默认 `8000`，可通过环境变量覆盖：

```powershell
$env:RAG_PORT="8011"
.\_start.ps1
```

## 3. VSCode 调试

1. 用 VSCode 打开项目根目录；
2. 左侧“运行和调试”选择 `RAG问答系统 (uvicorn)`；
3. 按 `F5`；
4. 等待调试控制台出现 `Uvicorn running on http://127.0.0.1:8000`；
5. 访问 <http://127.0.0.1:8000>。

调试配置没有启用 `--reload`，避免热重载子进程导致断点失效。

## 4. Docker Compose 部署

```powershell
Copy-Item .env.example .env
docker compose up -d --build
```

服务启动后访问 <http://localhost:8000>。`data/`、`vector_db/`、`logs/` 挂载到宿主机，MySQL 数据保存在 Docker volume 中。

常用命令：

```powershell
docker compose logs -f app
docker compose ps
docker compose down
```

注意：Linux 容器内无法调用 Word/WPS COM，旧版 `.doc` 请在 Windows 本机解析或先转换为 `.docx`。

## 5. 初始化样例知识库

仓库自带 6 份样例文档，位于 `data/samples/`。该脚本只重建样例本身的索引，不会删除各用户自己上传的知识库：

```powershell
.\venv\Scripts\python.exe scripts\index_samples.py
```

## 6. 邮箱验证码配置

在 `.env` 中配置 SMTP：

```dotenv
RAG_EMAIL_SMTP_HOST=smtp.163.com
RAG_EMAIL_SMTP_PORT=465
RAG_EMAIL_SMTP_USER=你的邮箱
RAG_EMAIL_SMTP_PASSWORD=你的邮箱授权码
RAG_EMAIL_FROM=你的邮箱
RAG_EMAIL_USE_SSL=1
```

`RAG_EMAIL_DEV_MODE=1` 仅在本地开发且未配置 SMTP 时使用，会把验证码直接显示在前端；生产环境必须为 `0`。

## 7. 生产部署建议

- 使用 Nginx 反向代理并启用 HTTPS；
- 通过环境变量设置强密码：`RAG_AUTH_PASSWORD`；
- 独立部署 MySQL，禁止使用默认 `root/root`；
- 将 `RAG_CORS_ORIGINS` 收紧为实际域名；
- 定期备份 `data/`、`vector_db/`、`logs/` 与 MySQL；
- 关闭 `RAG_EMAIL_DEV_MODE`，确保邮件验证码走真实 SMTP；
- 上传目录 `data/users/` 与向量库 `vector_db/` 不要提交到 Git。

## 8. 常见问题

### 访问页面提示 ERR_CONNECTION_REFUSED

通常是后端还没启动，或访问了错误端口。项目端口为 `8000`，启动后再访问 <http://127.0.0.1:8000>。

### 8000 端口被占用

```powershell
Get-NetTCPConnection -LocalPort 8000 -State Listen | Select-Object OwningProcess
Stop-Process -Id <PID> -Force
```

或改用 `8011` 启动。

### 上传 .doc 失败

确认本机已安装 Microsoft Word 或 WPS，并已安装：

```powershell
.\venv\Scripts\python.exe -m pip install pywin32
```

Linux/Docker 环境请先转换为 `.docx`。

### 普通用户看不到管理员上传的文档

这是预期的权限设计。普通用户的知识库只展示自己上传的文档，管理员可查看全站。
