# 数据库面试题库

## MySQL 索引

B+ 树索引按 key 有序存储叶子节点，适合范围查询和排序；哈希索引等值查找快，但不支持范围查询。联合索引遵循最左前缀原则，例如 (a,b,c) 可以命中 a、a,b、a,b,c 三类查询条件。覆盖索引避免回表，可以显著减少随机 IO。

## 事务隔离级别

MySQL InnoDB 默认隔离级别是可重复读，通过 MVCC 实现一致性快照。四种隔离级别分别是读未提交、读已提交、可重复读和串行化。可重复读下仍可能出现幻读，InnoDB 使用间隙锁和 next-key lock 在部分场景下避免幻读。

## 慢查询优化

先通过慢查询日志和 performance_schema 定位高频慢 SQL，再用 EXPLAIN 查看执行计划，重点检查 type、key、rows 和 Extra 字段。常见优化手段包括补索引、改写子查询为 JOIN、避免 SELECT *、对分页大偏移使用延迟关联。

## 分库分表

当单表数据量超过千万级或写入吞吐成为瓶颈时，可以按业务维度分库分表。水平分片常用 id 取模或范围分片，垂直拆分按字段访问频率拆分。分片后要处理全局主键、跨库 JOIN 和分布式事务，常见方案包括雪花 ID、应用层组装和最终一致性补偿。
