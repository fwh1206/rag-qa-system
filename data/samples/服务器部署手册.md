# 服务器部署手册

## Docker 部署

项目提供 Dockerfile 与 docker-compose.yml，一条命令 docker compose up -d --build 即可启动 FastAPI 应用和 MySQL。应用容器挂载 data、vector_db、logs 三个目录，MySQL 数据保存在独立 volume。

## 反向代理

生产环境建议使用 Nginx 反向代理，转发 443 端口到应用 8000 端口。SSE 接口需要关闭代理缓冲，否则流式输出会延迟；Nginx 中对应配置为 proxy_buffering off。

## HTTPS 配置

域名证书使用 Let's Encrypt 免费签发，通过 certbot 自动续期。证书文件挂载进 Nginx 容器，同时开启 HSTS 与 TLS 1.2 以上版本。敏感接口需要校验来源与鉴权头。

## 日志与监控

应用日志按 5MB 滚动保留 3 份历史。监控建议接入系统指标，包括 CPU、内存、磁盘、MySQL 连接数和 Chroma 磁盘占用。告警规则在 CPU 持续 90% 超过 10 分钟、磁盘使用率超过 80% 时触发。

## 发布流程

代码合并到 main 后自动构建镜像并打 tag，先发布到测试环境验证，再灰度到生产。数据库结构变更需要编写前向迁移脚本，回滚时优先恢复上一次发布版本而不是直接改数据。
